# HDEL 특허 현황 모니터링 대시보드
(Hyundai Elevator Patent & Intellectual Property Status Dashboard)

현대엘리베이터의 국내외 특허, 실용신안, 디자인, 상표 등 지식재산권 현황을 한눈에 파악하고 특허청(특허로/KIPRIS) 실시간 사건 진행상태와 법정 마감기한을 통합 모니터링하는 전용 대시보드입니다.

---

## 📊 주요 기능

1. **지식재산권 핵심 KPI 요약**
   - 총 보유 권리(1,248건), 심사·출원 진행(142건), 보유 등록 권리(986건)
   - 등록결정/설정등록료 납부대기(18건), 30일 이내 기한임박(5건), 계류 심판/분쟁(3건)

2. **포트폴리오 분석 및 시각화**
   - 권리 유형별 비중 (특허 59.5%, 상표 16.2%, 디자인 14.9%, 실용신안 9.5%)
   - 핵심 기술분야별 권리 분포 (스마트 제어/AI, 도어 시스템, 안전/비상제동, 로프/권상기)
   - 글로벌 패밀리 출원 국가 분포 (한국 KR, 미국 US, 중국 CN, 유럽 EP, PCT 국제출원)

3. **실시간 출원·심사 진행 파이프라인**
   - 출원 접수 ➔ 심사 진행 ➔ 의견제출통지(OA) ➔ 등록결정 ➔ 설정등록 5단계 라이프사이클 관제

4. **법정 마감기한 긴급 알림 위젯**
   - 30일 이내 도래하는 연차등록료 납부, OA 답변기한, 설정등록료 납부 기한 D-Day 실시간 알림

5. **특허청(KIPO) 실시간 출원·등록 마스터 테이블**
   - 실시간 다차원 필터링 및 통합 검색
   - 특허청 공식 서지사항(발명의 명칭, IPC, 발명자, 대리인, 심사관, 공보 초록, 심사진행 이력 타임라인) 상세 모달

6. **특허청 특허로 REST Web API 연계 게이트웨이**
   - 특허고객번호(`apagtCd`) 및 전자서명 인증키(`ctfctKey`) 연계 설정
   - Live 실시간 연동 및 데모 시뮬레이션 모드 지원
